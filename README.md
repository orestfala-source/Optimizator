# Optimizator: FPS-оптимізатор для Windows і macOS

Програма працює у треї (Windows) або в рядку меню (macOS) і чекає на гру.
Коли запускаєш **Minecraft (через лаунчер Zontas, Fabric або ванільний), Roblox, CS2** чи іншу гру зі списку,
буст вмикається сам. Після виходу з гри **все автоматично повертається як було**.

Стиль: модерний, темна тема, заокруглені кути. Колір акценту можна змінити: фіолетовий, зелений, жовтий, синій, червоний, рожевий або помаранчевий.

---

## 📦 Як отримати інсталери

### Варіант 1: автоматично через GitHub (нічого не треба встановлювати)
1. Створи новий репозиторій на GitHub і завантаж туди весь вміст цієї папки (разом із прихованою папкою `.github`).
2. Відкрий вкладку **Actions**. Збірка запуститься сама, якщо ні, натисни **Build installers → Run workflow**.
3. Приблизно через 10 хвилин відкрий запуск і внизу, в розділі **Artifacts**, завантаж:
   - `Optimizator-Windows`, а в ньому **Optimizator-Setup-1.0.0.exe**
   - `Optimizator-macOS`, а в ньому **Optimizator-1.0.0.dmg**
4. Для публічного релізу створи тег `v1.0.0`. Обидва інсталери з'являться у вкладці **Releases**.

### Варіант 2: зібрати на своєму комп'ютері
**Windows:** встанови [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) і двічі клацни `Windows\build-installer.bat`.
Inno Setup встановиться сам через winget. Результат буде тут: `Windows\dist\Optimizator-Setup-1.0.0.exe`.

**macOS:** виконай `xcode-select --install`, потім у Терміналі `bash macOS/build.sh`.
Результат буде тут: `macOS/dist/Optimizator-1.0.0.dmg`.

Версія береться з файлу `VERSION`: зміни число там, і обидва інсталери отримають нову версію.

## 🪟 Windows 10 / 11: що вміє інсталер
- Майстер встановлення українською (також English і Polski) з фірмовим оформленням.
- Якщо є диск **D:**, програма за замовчуванням ставиться в **`D:\Optimizator`**, інакше в Program Files. Папку можна змінити.
- Ярлик у меню «Пуск», за бажанням ярлик на робочому столі.
- Галочка «Запускати разом з Windows»: програма тихо стартує в треї з правами адміністратора, без запиту UAC.
- **.NET встановлювати не потрібно**, усе вже всередині.
- Під час оновлення стара версія коректно закривається сама.
- Програму можна видалити через «Параметри → Програми». Перед видаленням схема живлення і вентилятори повертаються в звичайний режим, а налаштування за бажанням можна залишити.

### Що робить програма під час гри
| Оптимізація | Що дає |
|---|---|
| Схема «Висока продуктивність» + «Найкраща продуктивність» | Процесор не скидає частоти, найбільший ефект на ноутбуках |
| Високий пріоритет гри | Гра першою отримує процесорний час |
| Без EcoQoS для гри | Windows 11 не переносить гру на енергоефективні ядра |
| Пригальмування фонових програм | Браузери, Discord, Steam, OneDrive отримують нижчий пріоритет (**не закриваються**) |
| Таймер 0.5 мс | Рівніший frametime |
| Дискретна відеокарта для гри | Ноутбуки: Minecraft (javaw.exe) і Roblox часто стартують на вбудованій графіці |
| Очищення кешу RAM (вимкнено за замовчуванням) | Для ПК з 8 ГБ RAM і менше |

Повторний запуск ярлика відкриває вже запущену програму з трею. Коли вікно сховане, біля годинника з'являються сповіщення «Буст увімкнено / вимкнено» (їх можна вимкнути).

### Вентилятори
Є ручний режим, повзунок 0–100 %, кнопки «Вимкнути», «Всі на максимум» і «Всі в авто». **Захист від перегріву** (за замовчуванням 90 °C) повертає всі вентилятори в авто.
Керування працює з материнськими платами та відеокартами NVIDIA/AMD. **На багатьох ноутбуках виробник блокує керування**: тоді програма лише показує температури та оберти, а змінити їх можна тільки в програмі виробника (Armoury Crate, Lenovo Vantage, MSI Center, OMEN Gaming Hub).
Якщо температура процесора або вентилятори материнської плати не відображаються, встанови драйвер **PawnIO** (його використовує бібліотека LibreHardwareMonitor).

## 🍎 macOS 13+ (Apple Silicon та Intel): що вміє інсталер
- Файл **`.dmg`**, усередині **«Встановити Optimizator.pkg»** і **«Видалити Optimizator.command»**.
- Інсталер `.pkg` зі своїм оформленням ставить програму в «Програми», **одразу встановлює системного помічника** (окремий запит пароля в програмі не потрібен) і запускає Optimizator.
- Під час оновлення стара версія коректно закривається.
- Видалити можна в самій програмі (**Налаштування → «Видалити Optimizator»**) або скриптом із `.dmg`.
- Universal-збірка (Apple Silicon + Intel), якщо збирати з повним Xcode або через GitHub.

### Що робить програма під час гри
- Вимикає **Low Power Mode**, а після гри вмикає назад, якщо він був увімкнений.
- Підвищує пріоритет гри та пригальмовує фонові програми.
- Не дає Mac заснути під час гри.
- За бажанням очищає неактивну пам'ять.

### Вентилятори
Ручні оберти в RPM, «Всі на максимум», «Всі в авто», захист від перегріву (95 °C). **Повністю зупинити вентилятор на Mac не можна**: Apple не дає опустити оберти нижче мінімуму. На Apple Silicon це неофіційний інтерфейс, тож на окремих моделях може не спрацювати. MacBook Air не має вентилятора.

## ⚠️ Перший запуск: попередження системи
Інсталери не підписані платним сертифікатом, тому:
- **Windows SmartScreen:** натисни «Докладніше → Виконати в будь-якому разі».
- **macOS:** якщо з'явиться «неможливо перевірити розробника», клацни по `.pkg` **правою кнопкою → Відкрити**, або відкрий Системні параметри → Конфіденційність і безпека → «Все одно відкрити».

Щоб попереджень не було взагалі, потрібні сертифікат підпису коду для Windows і Apple Developer ID ($99/рік) для Mac. Скрипт `macOS/build.sh` уже вміє підписувати: `SIGN_ID="Developer ID Application: …" bash macOS/build.sh`.

## 🎮 Ігри
Список за замовчуванням: Minecraft Java (Zontas / Fabric / ванільний), Minecraft Bedrock, Roblox, CS2, CS:GO, Valorant, Fortnite, Dota 2, GTA V, Apex, Rust, PUBG, League of Legends, Overwatch 2 (на Mac список свій).
Будь-яку іншу гру можна додати на вкладці «Ігри»: вкажи назву та ім'я процесу.

Minecraft визначається за аргументами java (слова `minecraft`, `fabricmc`, `zontas`), тому лаунчер Zontas Visuals підхоплюється автоматично. Сервери, запущені з `nogui`, грою не вважаються.

## Безпека й античити
Програма **нічого не впроваджує в гру** і не читає її пам'ять. Вона лише змінює пріоритет процесу, режим живлення та пріоритет фонових програм, так само як Диспетчер завдань. Якщо античит не дає доступу до процесу гри, цей крок пропускається, а решта оптимізацій працює.

## Чесно про FPS
Найбільший приріст буде на ноутбуках і на ПК, де стояв збалансований або енергоощадний режим, гра запускалася на вбудованій графіці чи працювало багато фонових програм. На потужному ПК, який і так працює на максимум, приріст невеликий. Заміряй FPS до і після.

## Структура
```
VERSION                      версія для обох платформ
.github/workflows/build.yml  автоматична збірка інсталерів на GitHub
Windows/                     програма (C# WPF, .NET 10) + installer/Optimizator.iss (Inno Setup)
macOS/                       програма (SwiftUI) + packaging/ (.pkg, .dmg, скрипти)
tools/make_assets.py         генерація іконок і графіки інсталерів
```
